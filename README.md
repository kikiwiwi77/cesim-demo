# BizSim 汽车商业模拟教学平台

一个可以在本机直接运行的中文教学模拟 Demo。教师端和学生端使用不同导航；学生的决策会进入汽车行业经营引擎，生成可追溯的团队结果。浏览器 `localStorage` 保存课程、轮次、提交和财务数据。

## 环境与启动

需要 Node.js 18 或更高版本，不需要 npm 安装依赖。

```powershell
node server.js
```

浏览器打开 <http://localhost:4173>。按 `Ctrl+C` 停止本地服务。项目不使用外部服务或账号密码；右上角的“角色视图”可切换教师端和学生端。学生端可在旁边的团队选择器切换演示团队。

## 演示内容

- 课程：汽车企业经营模拟课程
- 5 支企业团队、20 位演示学生、每队 4 人
- 共 6 轮，当前第 3 轮进行中，前 2 轮已有历史经营结果
- 初始资金 1 亿美元；燃油、纯电、混合动力产品；中国、欧洲、北美市场
- 学生初始演示团队：远航汽车（可从顶部切换其他团队）

## 操作流程

### 教师端

1. 在“工作台”查看课程、团队、提交率和最近活动。
2. 在“课程管理”创建或编辑课程，包括行业场景、区域、难度和初始企业资源。
3. 在“轮次管理”添加自定义轮次，设定开始和截止时间、决策修改规则和市场参数。未开始轮次可以删除或调整。
4. 在“学生与团队”添加学生、分配团队或新建企业团队。
5. 在“提交监控”追踪团队是否提交及提交时间。
6. 当前轮次团队决策提交后，在“轮次管理”选择“结束并计算”。若有团队未提交，教师可以确认后用该团队保存的草稿或默认方案结算。
7. 在“经营分析”切换历史轮次，查看结果、团队排名，并可导出 CSV。

### 学生端

1. 切换到“学生端”，选择要操作的团队。
2. 在“市场分析”查看需求、增长率、区域机会和原材料行情。
3. 在“经营决策”设置价格、产量、采购、营销、研发、融资和区域投入。
4. 点击“检查决策”验证输入，选择“保存草稿”或“提交本轮决策”。区域投入比例需要合计为 100%。
5. 教师允许修改时，学生可以更新已提交决策；教师结束轮次后，决策锁定。
6. 在“财务与排名”查看按轮保存的收入、利润、生产成本、现金流、库存和综合得分。

## 经营引擎说明

`engine.js` 是纯计算模块，UI 与持久化在 `app.js`。每次结算保存市场参数快照、团队决策输入、逐团队结果和财务报表。计算包含价格弹性、营销与研发竞争力、区域机会、团队间竞争、产能约束、期初库存、采购材料成本、贷款利息、资本支出、现金流、期末库存和综合得分。结果不是随机数。

数据以包含 `User`、`Teacher`、`Student`、`Course`、`Simulation`、`Scenario`、`Team`、`TeamMember`、`Round`、`MarketCondition`、`Product`、`Decision`、`DecisionSubmission`、`SimulationResult`、`FinancialStatement` 和 `Leaderboard` 集合的本地 JSON 状态保存；集合使用稳定 ID 进行关联，适合后续迁移至 API、PostgreSQL 和 Prisma。

## 重置演示

教师端侧栏底部的“重置演示数据”会恢复内置的课程、团队、学生、六轮模拟和历史结果。所有演示数据只保存在当前浏览器的本地存储中。

## 独立演示入口

教师端：<http://localhost:4173/teacher>，账号 `teacher@bizsim.edu`，密码 `teacher123`。
学生端：<http://localhost:4173/student>，从名册选择学生账号，密码 `student123`。每个学生账号自动绑定自己的团队；教师端和学生端需要分别登录。首页 <http://localhost:4173> 提供入口选择。

教师编辑课程时可以勾选学生市场简报模块。市场页以文字摘要展示所选的需求预测、成本、消费者、竞争、区域、原材料和可持续发展内容。

详细参数公式、数据流转和当前模型边界见 [模拟参数与数据流说明.md](./模拟参数与数据流说明.md)。

## 发布到 GitHub Pages

仓库已包含 Pages 自动发布工作流：推送到 `main` 分支后，GitHub Actions 会构建静态文件并发布。首次使用时，在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。发布成功后，项目站点地址通常为 `https://<用户名>.github.io/<仓库名>/`。

也可以在本机预先生成发布目录：

```bash
node scripts/prepare-pages.cjs
```

GitHub Pages 是静态托管；演示数据保存在每位访问者自己的浏览器 `localStorage`。教师和学生用不同设备访问时，提交数据不会自动共享。跨设备协作需要再接入服务端数据库。
